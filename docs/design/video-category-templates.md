## 共同约束

- **原标题逐字保留。** HTML title/H1和Markdown H1一致，栏目名在标题之外。无标题本地录音使用用户提供名称或文件名，并明确来源，不编造“视频原标题”。
- **正文依原片展开。** 保留讲述节奏、故事、例子、追问、反例、条件及更正，删掉重复口头语。写得自然生动，不冒充作者亲历，不虚构对白或情绪。
- **新增评论独立。** 紫色虚线卡和文字标签同时标记“AI观点 · 非原片内容”，打印仍能辨认。判断、期待和追问可以大胆，但不倒写成原作者的主张。没有有价值的评论就省略，正式实录尤其如此。
- **图片按信息价值选择。** 原帧附来源、实际时间和图注；没有有效画面就不配图。不用生成图、占位图或未经读取的帧冒充视觉证据。
- **时间、人物、结论有依据。** 时间轴缺失不猜时间，身份不明标说话者A/B，无法确认的内容注明疑点。口述回忆、当事人说法、旁白判断与可见事实分别归属。
- **作者语气优先于分类默认。** 搞笑讲座可以活泼，正式科技可以克制；装饰和评论尺度跟随受众及内容，不改变事实边界。

## 八类主模板

| 主类 / 栏目 | 总结价值 | 结构与行文 | 视觉与组件 | 新增评论 |
|---|---|---|---|---|
| 科技数码 / 折腾实验室 | 理解工具、复现步骤、比较效果 | 动机→搭建→效果与代价→玩法；具体、有趣、懂行 | 柠檬黄/薄荷绿、网格纸、操作原帧 | 加餐：产品取舍、替代路线、未来玩法 |
| 课程讲座 / 听懂笔记本 | 学习和复习，找回推导与问答 | 问题→定义→推导→例子→问答；沿讲者思路递进 | 暖白/靛蓝、荧光标记、复习提纲、板书和幻灯片 | 课后追问：假设、迁移、新问题 |
| 访谈播客 / 长谈会客厅 | 归纳长谈，比较不同人的观点 | 议题→问答→追问→分歧/修正→未决；保留说话归属与故事 | 葡萄紫/蜜桃色、对话卡、观点对照、议题索引 | 换个角度：独立立场，不冒充嘉宾共识 |

| 严肃科普 / 原理观察室 | 听懂机制、证据与适用条件 | 问题→机制→证据→限制；清楚、克制，保留直观类比 | 冷白/深蓝、装置图、机制图、条件卡 | 延伸思考：反例、实验与替代解释 |
| 知识评论 / 观点拆解台 | 理解论点，检查推理与材料 | 主张→理由/案例→反例/限定→结论；有锋芒、有归属 | 纸白/黑墨/砖红、杂志标题、论证卡 | 另一种看法：质疑论证、换一个视角 |
| 纪录纪实 / 现场观察簿 | 理解事件进程、人物处境和不同材料 | 背景→人物/事件→不同视角→变化/疑问；场景具体，判断有归属 | 砂岩白/墨绿/赭黄、场记、现场原帧、时间线 | 现场之外：材料遗漏、叙事视角、结构性问题 |
| 影视剧情 / 故事放映室 | 整理长剧情、人物关系和解说思路 | 不剧透开场→人物→冲突→结果/伏笔；保留情绪与悬念 | 深蓝/暖金、胶片框、默认收起的剧透区 | 观后想法：剧情解读、主题与猜测 |

生活体验 / 日常手帐作为扩展：奶油色与草绿、照片与路线节点、亲切具体的体验叙述。适合有路线、步骤或经验价值的长Vlog、游记、手作；不为每段日常流水账强行总结。

## 讲座、访谈与录音怎样区分

**内容类型与输入媒介分开。** 讲座可以是视频或录音，播客也可以有画面；“录音实录”是没有更合适结构的会议、现场讲话、口述记录等材料的整理方式，不把所有音频都放进同一个模板。

先明确用户目的，再看完整素材的主结构，最后决定画面组件：

1. 用户指定模板、无剧透或实录要求时优先遵从。
2. 围绕系统教学、概念递进和问答展开，用讲座；围绕机制与实验解释问题，用科普；围绕主张与论证展开，用知识评论。
3. 多人对话的追问和分歧重要，用访谈；需要回查原话、记录明确决定，用实录。口述历史采访可用访谈；经过叙事编排、材料串联的纪实内容可用纪录纪实。
4. 工具操作与评测用科技；人物行动和剧情转折用影视；事件现场、当事人和档案材料构成主线，用纪实。
5. 单独记录输入媒介、有效画面及可靠时间轴。纯音频和静态封面视频不抽封面充数；可用议题索引、复习提纲、观点对照和回听入口。
6. 无法确定主类时保留原有顺序，采用中性骨架；次级主题不另起一套视觉，不只靠标题关键词分类。

| 素材 | 主类与呈现 |
|---|---|
| 两小时大学课程录像 | 讲座；前置概念、推导、例题、问答，信息丰富的板书原帧 |
| 同一课程的录音 | 讲座 + 纯音频；保留教学结构，用真实回听索引代替图片 |
| 科学家多人圆桌 | 访谈；科学是主题，观点分歧与问答是结构 |
| 静态封面的视频播客 | 访谈 + 纯音频呈现；省略封面，不循环截图 |
| 项目复盘录音 | 实录；议题、发言、未决项，明确说过才写决定/负责人/期限 |
| 个人口述回忆录音 | 实录或访谈；明确是当事人回忆，不自动写成核实史实 |
| 讲手机自动化原理并演示操作 | 以主要观看目的选科技或科普，继承原片的轻快语气 |
| 历史讲座中集中提出并论证观点 | 以教学或论证主结构选讲座或知识评论，保留引用层级 |
| 城市变化纪录片 | 纪实；时间进程、现场动作、当事人说法与旁白分开 |
| 长篇剧集解说 | 影视；转折、谜底、截图和相关AI评论统一进入剧透区 |

## 各类重点边界

- 讲座：不将推导压成金句；公式、符号和条件从真实材料核对，板书模糊时不补猜。没回答的课堂提问保留为未回答，AI练习和解法另列。复习提纲不替代完整论证。
- 访谈：对照卡仅整理实际观点，不能制造二元对立；追问带来的修正跟着该说话者走。身份只能从可靠材料确认，不能根据音色猜姓名；转录文本不够时不猜情绪、讽刺或打断。
- 实录：决定、建议、分歧、未决项分开。未提负责人和日期就写未明确，不补一张虚构待办表。纯音频不配假截图或装饰波形。没有可用回听URL就省略链接，不制造坏链接；没有可靠时间轴改用议题索引并标缺口。
- 科技：保留步骤依赖、环境与限制，不将一次演示推广成普遍兼容。术语穿插解释，截图优先界面入口、系统关系与前后状态。
- 科普：观察、解释、假设和预测分开；单位、条件、反例与更正跟着结论走，类比不充当证据。
- 评论：保留作者推理、引用层级与反例；预测不写成已发生事实，尖锐评论不替代核验。
- 纪实：区分旁白、当事人、档案与现场。只有材料明确时才标重演或历史影像；镜头呈现不能独自证明因果，人物表情不直接证明内心。
- 影视：转折、谜底、结果及对应图片和评论默认收起。打印保持当前展开状态；Markdown无可靠折叠，无剧透稿要实际删掉相关内容。原标题含剧透仍保留，并提醒读者。

## 文件与验证范围

profiles.json定义八类主配置及生活扩展；base.css承载来源与评论标识、时间线与对照组件，themes.css定义各类视觉。生成器输出九组HTML/Markdown骨架和八类本地预览，不下载素材、不调用模型，未接入生产分类器或CLI。

纯音频录音骨架已经省略图片。其他类别的骨架是可编辑写作合同：处理纯音频讲座或访谈时必须省略图片，换成真实索引；目前没有自动检测媒介或自动切换渲染器。骨架填充需转义内容、校验路径和URL，不能接收模型生成的任意脚本。

本轮通过本地浏览器集成检查覆盖八类切换、桌面/390px/320px、HTML与Markdown生成、录音无图、标题与评论归属、剧透和打印。正式内容质量还需分别选真实讲座、访谈和录音检验完整覆盖、归属与时间准确性；合成样片只能证明模板和交互。

后续接入沿用[字幕—画面证据流程](illustrated-summary.md)：输入媒介与编辑类型分别记录；正文证据与新增评论分别保存；仅在有效画面存在时抽帧理解与配图。真实原标题来自素材元数据，录音缺少标题时采用明确提供的名称。
