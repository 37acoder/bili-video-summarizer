# 本地转录问题修复与 OpenCode 实际重测

测试日期：2026-10-11。目标：[BV12ftJ6rEkw，P1](https://www.bilibili.com/video/BV12ftJ6rEkw/?p=1)。本次按仅文字模式验收；不改变默认图文模式。

## 已修复的问题

- 将字幕身份异常的恢复限制在 CLI 同一个前台进程：`--caption-retries 0..3`，默认不重试，仅重试 `CAPTIONS_INVALID`。HTTP、鉴权、JSON 解析和取消保留实际错误，不触发本地转录。B站字幕下载不再吞掉 HTTP/解析失败。
- 新增按需读取的执行说明，要求等待进程结束、保留旧输出目录，禁止用后台任务、shell 重试循环和删除目录恢复任务。有效阶段缓存可在新输出目录复用。
- Map、Reduce 和最终稿均保留转录疑点与原文来源；语境猜测写成“可能，未核实”，不能改写成确定纠错。
- 新增 `verify-summary`，校验原标题、章节数、来源 item/秒数/引文、向下取整的标题时间，以及正文引用早于章起点的问题；扫描 map/reduce/正文中的确定纠错措辞。Skill 交付前必须通过校验并有界核对语义。

## 真实失败与修订

本次并非首次生成即全部通过。第一次任务的初稿仍有确定纠错措辞，经追加提示后同步修订 Map/Reduce/正文。第二次初稿虽然引文存在，新增校验发现 6 个章节问题：第 2、5、6、8、11 章起点晚于正文引用的内容，第 4 章把 330.68 秒标成 05:31。

保留初稿后，同一 OpenCode 会话读取新版校验流程并修订：将更早内容移至前一章或提前起点、收紧过宽的引用范围、改用向下取整的 05:30，随后重新校验。12 章最终时间为 00:00、01:55、03:08、05:30、08:05、11:57、14:47、17:42、21:41、25:26、30:42、32:35。协调者另用实际发布脚本独立复核通过。

首段“科技起点”、中段“2026年11月到2019年1月”、尾段“2023年年底达到5.3万亿美元”等疑点保留原文与 item 时间，并标记未核实；没有将常识推测包装为已确认纠正。详细疑点见最终总结及 Worker 报告。
