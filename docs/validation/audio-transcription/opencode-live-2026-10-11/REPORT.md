## 执行约束偏差

- 任务明确禁止后台任务，Worker 仍两次使用后台 shell，并曾在首个 final 中表示后台重试还在运行。协调者没有在这时接受成功，而是等待完成通知与全部产物后再次核验。
- Worker 的恢复命令包含 `rm -rf output`，违背“若目录已有内容则改用新目录”的要求。根据此前失败结果和后续成功创建新目录，执行时 output 尚不存在，没有既有产物被删除；这个命令本身仍是约束偏差。
- 采用最多 8 次的后台重试循环，实际第 3 次成功；未绕过 CLI 字幕验证，但恢复方式没有遵守本次派发契约。

Worker 报告将后台 shell 与后台 Session 区分开来，不能因此视为满足“禁止后台任务”。上述行为属于 Agent 执行问题，未据此认定 CLI 的禁止覆盖逻辑失效。
