# 文字总结行文改版验收

日期：2026-10-11。范围为video-summarizer技能的文字分支和共用编辑规则；旧库API的outline/bullets选项保持其现有语义。

## 改动与按需加载

文字分支默认使用原标题、导语、内容小标题和自然段落；保留原片故事、推理、例子、条件和更正。用户指定速览、提纲或会议纪要时按用途组织。AI评论采用独立引用块，逐块标记“AI观点 · 非原片内容”；实录默认省略评论。

两种分支写作时读取references/editorial-writing.md及所选的一份assets/editorial/profiles配置。配置从现有分类源生成，共用voice、structure、评论规则及剧透边界；文字分支不加载图片策略、视觉流程、HTML或CSS。图文分支继续加载所选视觉主题。

## 真实字幕写作验证

[文字样例](../../../../examples/text-summary/summary.md)使用BV1KLhi6oEh5的仓库字幕和已有原标题元数据。prepare生成2块、49项，逐块读取后按五个内容转折写作；正文范围覆盖开场演示、部署、插件与语音入口、权限边界、本机配对、控制原理、救急应用及结尾期待。没有从图文稿迁入视觉新增信息。

[章节证据](../../../../examples/text-summary/chapters.json)包含输入SHA-256及每章首个来源索引、实际秒数、短引文和覆盖索引。程序核验原标题、5章标题与向下取整的时间、引文与来源项逐一匹配，49项覆盖完整且不重复；输出没有图片标记，2处AI观点均显式标归属。逐章回读确认章节标题与开头内容由对应来源支持。专名识别疑点保留，不据此补写安装命令。

## 同日补充：AI观点的分析深度

共用行文增加独立分析与交付自检：每处评论须从具体材料出发，推进假设、机制、竞争解释、取舍或迁移分析，并给出判断、成立条件或明确的证据缺口。赞同与反对均需要理由；只有泛泛赞美、复述或未展开的追问时重写或省略，不靠反对作者制造深度。

文字样例的两处评论已改为：①分析主动配对与任务授权之间的缺口，以及逐步确认可能转移的监看成本；②区分救急案例中临时开发与屏幕控制的贡献，把准备、排错、核验和清理计入成本，提出可改变判断的比较方式。假想画布任务明确标为假设，正文、章节来源和时间保持原状。

同一分类源中九类commentStyle与合成评论示例同步更新，并重新生成图文骨架、画廊及两套配置。历史真实图文样例保留原版本；新版要求作用于后续两种模式的写作。重新执行模板打包及4项技能集成测试通过。对文字样例复核原标题、5个章节时间、49项覆盖与2处评论归属通过；规则及配置已同步本机共享技能。这是人工行文验证，不以程序断言冒充深度质量评测。
