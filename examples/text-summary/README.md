# 仅文字总结改版样例

[summary.md](summary.md)使用与图文版相同的视频原标题和科技行文风格，但正文只依据[仓库字幕](../samples/BV1KLhi6oEh5.input.txt)。它是宿主Agent按新版技能写作规则完成的示例，不是旧LLM API默认outline格式的自动输出。

字幕经prepare分成两块后逐块读取，正文五章覆盖全部49项；[chapters.json](chapters.json)记录各章首个来源项、秒数与短引文。评论单独标记，转录专名疑点保留，没有从图文样例借入画面结论。核验记录见[文字模板改版验收](../../docs/validation/visual-summary/skill/text-summary-revision.md)。
