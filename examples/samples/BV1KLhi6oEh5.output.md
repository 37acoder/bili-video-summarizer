## 一句话总结
本视频手把手教你把 DeepSeek Harness 部署到安卓手机或平板（基于小米14 Pro和小米Pad 9实测），通过无线 ADB 让本地 AI Agent 获得操控设备的能力，打造一个比 Siri 更强大的语音助手。

## 章节要点
### [00:00] 开场：出差照片引发的折腾
- 作者出差回来被网友调侃"头发炸毛像被雷击"，用AI助手幽默回应"头发还在云端巡航"
- 让AI助手给自己画素描，借此引出主题：绝大多数安卓设备都能拥有一个比 Siri 更 Siri 的语音助手
- 演示设备为几年前的小米14 Pro和小米Pad 9

### [01:07] DeepSeek Harness 能力与实战演示
- 上期视频已分享如何把 DeepSeek Harness 装到平板，给它本地环境来开发安卓应用和小游戏
- 它还能被语音控制，变成" Siri 本应该成为的样子"
- 本期是上期承诺的手把手教程，建议关注收藏后再看

### [01:41] 准备工作：开发者模式与无线调试
- 软件来自开源项目（将 DeepSeek Harness 封装到安卓），作者在自己的分支上做了改造并开源，但建议使用主线仓库（分支不频繁更新，适合有能力魔改的人）
- 打开开发者模式：狂点 OS 版本；核心是打开 USB 调试和无线调试
- 在无线调试里输入配对码，把码、地址和端口给同一局域网内的 AI，让它下载 ADB 环境完成配对

### [03:17] 部署 DeepSeek Harness 与插件配置
- 通过电脑端 agent 用 ADB 给手机装应用、传文件、截屏读界面、模拟点击滑动打字（相当于给电脑一双眼睛和一只手）
- 演示用小窗口/后台方式让 DeepSeek Harness 完成 ADB 无线配对（端口 54180、32981），这一步比较有技巧
- 作者自建插件：深海微光启动画面、codex 登录按钮、本地部署千问3 ASR/TTS 并接入 API 可选语音输入输出
- 推荐小米蓝牙遥控器（约50元）作为 web coding 神器，是蓝牙麦克风+按键组合，可语音键开启、确认键发送、删除

### [05:33] 赋予 Agent ADB 权限：原理与风险
- 目前 DeepSeek Harness 还不具备操作设备权限，需要特殊操作让它获得 ADB 权限（相当于"阳股和重股"——让本机环境里的 agent 通过本机地址操作自己）
- 风险声明：ADB 权限极大，AI 能力差或无视觉就可能看不懂屏幕、误判界面，比如在错误 app 发消息、改错设置、误删文件
- 它能安装卸载应用、调整部分系统权限，但受安卓本身权限约束；云端 API 用户要格外小心隐私和资金界面；不想让它动就关掉无线调试或删除配对

### [08:12] 控制设备原理、应用场景与总结
- 原理不复杂，就是"看→动手→再检查"的循环：AI 通过 ADB 截屏或读取界面按钮文字，判断该做什么，再执行点击滑动输入，然后重新检查
- 画画用 informative drawings 模型把照片变线稿再转触控路径，配合模拟笔压和灰度表现笔触——看起来是 AI 在画，实际是程序在画
- 作者出差只带平板踩了坑（LUT 在旧电脑、iPhone 素材上传不便），于是让 DeepSeek Harness 开发"救急应用"：开启服务器扫码上传素材并自动套 LUT，基本可代替笔记本
- 安卓生态比 iOS 好玩太多，ADB 应该是 agent 的 harness，甚至值得开发更高效的 CLI；老设备也值得折腾

## 关键结论
- 绝大多数安卓设备（实测安卓16的小米14 Pro和安卓17的小米Pad 9）都能通过无线 ADB + DeepSeek Harness 获得一个远超 Siri 的本地语音助手，缺点是速度偏慢。
- 部署关键在于开发者模式、USB/无线调试、配对码在同局域网传给 AI，以及用"看→动手→再检查"的循环赋予 agent ADB 权限。
- ADB 权限极大且有风险（误操作、隐私泄露），务必评估后使用，不用时关掉无线调试或删除配对即可立即断开。
- 平板 + DeepSeek Harness 可开发"救急应用"（如扫码上传素材、自动套 LUT），在出差场景基本可替代笔记本，安卓的自由生态在 AI Agent 时代玩法更多。
