# 命令完成与失败恢复

prepare以前台运行；宿主shell支持timeout时，给转录留出至少600000毫秒，并设置background=false。返回运行句柄时，用宿主的等待或轮询接口等待进程结束。宿主禁止后台或子任务时，继续使用同一前台流程。完成标准：全部关联进程成功结束、清单存在且inspect成功，之后才进入总结。

遇到 CAPTIONS_INVALID，可在原 prepare 命令上显式加 --caption-retries 3。CLI 只对该错误最多重试三次，在同一前台进程报告 caption-retry 进度；耗尽后交付实际错误，不再包 shell 重试循环。HTTP、鉴权、JSON 解析及取消不由此选项重试。每次仍重新核验平台字幕；只有明确缺失才进入 ASR。

输出目录已存在时保留它，改用新的同级目录；目录尚未创建时可沿用原定路径。有效阶段缓存继续使用同一--asr-cache-dir，它与输出目录分别管理。恢复时复用有效缓存，保留旧目录中的结果与失败记录，不删除、清空或重建旧目录。
