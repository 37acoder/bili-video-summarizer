# 命令完成与失败恢复

prepare 使用前台调用：宿主 shell 支持 timeout 时给转录留出至少 600000 毫秒，并设置 background=false。调用返回运行句柄时，使用宿主等待/轮询接口直到进程结束；全部关联进程结束、清单存在且 inspect 成功后才进入总结或交付。宿主契约禁止后台或子任务时，沿用同一个前台执行与等待流程。

遇到 CAPTIONS_INVALID，可在原 prepare 命令上显式加 --caption-retries 3。CLI 只对该错误最多重试三次，在同一前台进程报告 caption-retry 进度；耗尽后交付实际错误，不再包 shell 重试循环。HTTP、鉴权、JSON 解析及取消不由此选项重试。每次仍重新核验平台字幕；只有明确缺失才进入 ASR。

输出目录有内容或已有目录时，保留它并选新的同级目录。有效阶段缓存继续使用同一 --asr-cache-dir，输出目录与阶段缓存是两个位置。不要删除、清空或重建旧输出目录来恢复。即使目录尚未出现也直接重用该路径或选择新路径，无需删除命令。
