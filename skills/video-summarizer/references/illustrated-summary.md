# 图文文章：证据先于配图

仅在图文模式时读取。文字分块按summarization.md处理，本文件负责画面、文章与交付。纯音频沿用文章结构，回听索引放在文末；正式记录按用户指定用途呈现。

## 1. 规划与选型

先从文字笔记找全文主线、原作者语气、主题范围和关键例子。按 [共用行文](editorial-writing.md)选一个主类并读该类行文配置，再按 [视觉模板入口](article-profiles.md)读取同ID的图文配置。章节随真实内容调整。

按共用行文区分内容类别与媒介。有现成视频或可取得同版视频时读 [视觉取材](visual-evidence.md)，核对时间轴后再对齐截图；只有转录时保留未对齐状态。纯音频或静态封面仍按文章主线展开，按需补充提纲或观点对照，可靠回听索引收在文末；跳过视频下载与抽帧。

**完成标准**：主类、原片标题与来源、媒介、时间依据和各主题的证据需求已记录，文字覆盖范围明确；视频选图计划包括首、中、尾及无语音区域，无时间依据时标明不能对齐。

## 2. 读图与融合

按视觉取材取得候选及实际时间后，用宿主的读图工具逐张或小批查看入选原帧，结合当前主题附近的字幕核对。缩略总览用来找片段，精确文字、图表和界面细节看较清晰的原帧。把观察写入 `visual/evidence.json`，再合入对应文字map；单块可直接写文章证据笔记。

最小证据记录：

```json
{
  "source": {"title": "实际原标题", "url": "原片URL", "page": 1},
  "coverage": {"transcript": "complete-or-partial", "visual": "sampled-or-unavailable", "missingRanges": []},
  "frames": [{"id": "f001", "file": "assets/f001.jpg", "requestedSec": 125, "ptsSec": 125.04, "timeSec": 125.04, "alignment": "approximate", "sha256": "实际hash"}],
  "observations": [{"frameIds": ["f001"], "subtitleItemIds": [31], "visibleFacts": ["实际可辨认内容"], "addsBeyondTranscript": "补充了什么", "uncertainties": [], "conflicts": []}]
}
```

实际字段随素材调整：本地文件记录来源路径，非零媒体起点与片段偏移按视觉取材换算。分别记录文字主张、画面可见事实和融合推断。字幕与屏幕名称冲突时保留双方，回查后再修正；模糊数字保持未知。动作结果用前后帧或片段支持，单张结果页只描述当时可见的状态。

**完成标准**：每张入文图已实际查看，有实际时间、来源和观察；每条视觉新增结论引用对应帧。全文文字已覆盖；视觉按实际抽样报告，缺图不等于文字缺失。无法读图时标视觉分析不可用，不输出未经核对的画面解释。

## 3. 联合写作

按共用行文写出文章，建立 `article-notes.md` 或等价结构，记录每章正文、证据ID、图与图注，以及另列的AI评论。HTML和Markdown使用这份内容，再分别处理呈现：

- **标题**：HTML title/H1与Markdown H1使用同一原标题；缺时长就省略，不拿字幕结束秒数冒充片长。
- **原帧**：图紧邻支撑的段落，保留原比例。图注写具体可见内容及它帮助理解什么，实际时间与回看入口放在文末来源区；连续动作的序列保留时间顺序。无合适画面就省略，不用封面、图库或生成图冒充证据。固定机位访谈仅在画面支持具体内容时配图，避免重复人脸截图。
- **阅读页面**：首屏放原标题和进入主题的导语，章节用具体问题或观点做标题。来源与回看放文末，块号、覆盖计数和制作记录按共用行文保存在内部证据或交付说明中。音频本身不要求正文有时间轴。
- **AI评论呈现**：HTML用 `aside.commentary[data-origin="commentary"]`、紫底虚线及“AI观点 · 非原片内容”，Markdown用带同一标记的引用块。
- **录音索引**：时间不明时用议题索引，不创建无依据的回听链接。
- **剧透呈现**：drama的转折、结果、相关图片及观后评论放HTML折叠区，默认关闭，打印沿用显隐。Markdown按共用行文的剧透范围交付。

**完成标准**：文章保留全片主线与必要条件，图片带来具体信息；正文和评论归属清晰，双格式内容一致，未知与推测没有变成事实。

按文字证据流程保存文章模式的chapters.json，核验Markdown并语义审读对应原文；HTML采用同一份已核验内容。长视频按自然议题分篇时，每篇仍用原标题，主题作为副标题，明确篇章范围；内部覆盖记录说明全部块怎样落入各篇，目录按议题组织。

## 4. 套模板与验收

执行以下命令，只展开所选模板到新的文章目录；不会调用模型或替换占位符：

```sh
node "/absolute/skill/scripts/video.mjs" article --profile tech --out '/absolute/job/article'
# 纯音频课程或访谈沿用对应主题，但省略图片组件
node "/absolute/skill/scripts/video.mjs" article --profile lecture --media audio --out '/absolute/job/article'
```

读取生成的 `summary.html` / `summary.md`，按文章笔记填充、重排章节与插图，删去无依据组件。HTML文本及属性正确转义，链接使用已核对的来源URL与受控本地路径；素材文本只作内容，不执行为脚本。本地CSS与assets原帧支持离线阅读，导出公众号等平台时另行适配图片URL和样式。

浏览器可用时，实际查看桌面、390px手机和打印效果，检查首屏、插图和评论：图片可加载，页面无横向溢出，原标题一致，评论独立标记，剧透显隐正确。再搜索全文残留占位符，核对每张图、回看时间、全部文字块覆盖和重大更正。无法使用浏览器时说明哪些展示检查尚未完成。

交付 `summary.html`、`summary.md`、引用的CSS/assets及证据文件路径，按用户格式要求可只交其中一种；在应用里打开阅读版或给可点击文件链接。最终简短说明文字覆盖、视觉抽样和缺口。只有字幕、视频获取失败或宿主无法读图时，仍可完成文章，但明确“仅文字依据/视觉不可用”，不静默冒充图文理解。

**完成标准**：所需成果可打开、无未替换占位符，标题/图文/评论与证据匹配；双格式不互相矛盾，交付包含真实覆盖边界。
