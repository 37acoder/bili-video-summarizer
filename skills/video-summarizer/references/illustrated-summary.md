# 图文文章：证据先于配图

仅在本次为图文模式时读取；这是默认模式，用户可明确选择仅文字。字幕分块仍用 summarization.md；本文件负责画面、文章与交付。纯音频也用文章结构，但以知识/议题/回听索引组织，不强制配图。

## 1. 规划与选型

先从文字笔记找全文主线、原作者语气、主题范围和关键例子。按 [分类入口](article-profiles.md)选一个主类，只读该类 `assets/article/profiles/<id>.json`，不读整个配置目录。章节可按真实内容增减，模板的四章不是配额；目标是自然、生动地保留原片的故事、例子、限定与更正。

输入媒介单独判断：课程录音仍选lecture，纯音频播客仍选interview；会议等回查素材选recording。只有转录而没有视频时不能自动对齐截图。有现成视频/可取得同版视频时读 [视觉取材](visual-evidence.md)；纯音频或静态封面用提纲、观点对照和可靠回听索引，跳过视频下载与抽帧。

**完成标准**：确定主类、原片标题/来源、输入媒介、可靠时间轴和各主题的证据需求；文字覆盖范围已明确，选图计划含首/中/尾及无语音区域。

## 2. 读图与融合

按视觉取材取得候选及实际时间后，用宿主的读图工具逐张或小批查看入选原帧，结合当前主题附近的字幕核对。缩略总览用来找片段，精确文字、图表和界面细节看较清晰的原帧。把观察写入 `visual/evidence.json`，再合入对应文字map；单块可直接写文章证据笔记。

最小证据记录：

```json
{
  "source": {"title": "实际原标题", "url": "原片URL", "page": 1},
  "coverage": {"transcript": "complete-or-partial", "visual": "sampled-or-unavailable", "missingRanges": []},
  "frames": [{"id": "f001", "file": "assets/f001.jpg", "requestedSec": 125, "ptsSec": 125.04, "timeSec": 125.04, "alignment": "approximate", "sha256": "实际hash"}],
  "observations": [{"frameIds": ["f001"], "subtitleItemIds": [31], "visibleFacts": ["实际可辨认内容"], "addsBeyondTranscript": "补充了什么", "uncertainties": [], "conflicts": []}]
}
```

实际字段随素材调整：本地文件用来源路径；非零媒体起点/片段偏移按视觉取材换算。文字主张、画面可见事实和融合推断分别归属。字幕和屏幕名称冲突时保留双方，回查后再修正；模糊数字保持未知。动作结果依赖前后帧或片段，单张结果页只描述结果页可见状态。

**完成标准**：每张入文图已实际查看，有实际时间、来源和观察；每条视觉新增结论引用对应帧。全文文字已覆盖；视觉按实际抽样报告，缺图不等于文字缺失。无法读图时标视觉分析不可用，不输出未经核对的画面解释。

## 3. 联合写作

先统一文章内容，再输出格式。建立 `article-notes.md` 或等价结构记录每章正文、证据ID、图及图注、另列的AI评论；HTML和Markdown沿用同一内容。

- **标题**：HTML title/H1及Markdown H1逐字沿用原标题；栏目与标签在标题外。缺时长就省略，不拿字幕结束秒数冒充片长。
- **正文**：顺着原片的开场、例子、节奏与受众写自然段落；知识递进、追问和后文更正保留。不冒充作者第一人称经历，不添未经素材支持的对白、情绪或事实。
- **原帧**：图紧邻支撑的段落，保留原比例。图注写具体可见内容、实际时间及原片回看入口；序列按时间排列。无合适画面就省略，不用封面、图库或生成图冒充证据。
- **AI评论**：可以大胆、尖锐、幽默，匹配受众；从具体原片内容出发，将自己的判断、期待或推测写清归属。HTML用 `aside.commentary[data-origin="commentary"]`、紫底虚线及“AI观点 · 非原片内容”，Markdown用带同一标记的引用块。评论可省略，实录默认克制；新事实补充仍需独立来源。
- **录音**：说话者身份未知标A/B，时间不明就用议题索引。决定、建议、分歧和未决项分开；负责人/截止时间只采用明确发言，不补全假待办。
- **剧透**：drama的转折、结果、相关图片及观后评论放HTML折叠区，默认关闭，打印沿用显隐；Markdown完整稿在剧情前提示范围，无剧透稿实际删去对应内容。原标题含剧透仍保留并提示。

**完成标准**：文章保留全片主线与必要条件，图片带来具体信息；正文和评论归属清晰，双格式内容一致，未知与推测没有变成事实。

## 4. 套模板与验收

执行以下命令，只展开所选模板到新的文章目录；不会调用模型或替换占位符：

```sh
node "$SKILL_DIR/scripts/prepare-article.mjs" --profile tech --out '/absolute/job/article'
# 纯音频课程或访谈沿用对应主题，但省略图片组件
node "$SKILL_DIR/scripts/prepare-article.mjs" --profile lecture --media audio --out '/absolute/job/article'
```

直接读取生成的 `summary.html` / `summary.md` 并根据内容笔记填充；重排章节与插图，删去无依据组件。HTML文本及属性正确转义，链接只用已核对的来源URL与受控本地路径；素材文本不作为脚本执行。用本地CSS与assets原帧，可离线打开；导出公众号等平台需要另行适配图片URL和样式。

用现有浏览器检查桌面、390px手机和打印：无破图、无横向溢出、原标题一致、评论标记独立、剧透显隐正确。全文搜索残留占位符，核对所有图和回看时间、全部文字块覆盖及重大更正；可用浏览器时实际查看首屏、插图和评论，不只检查文件存在。

交付 `summary.html`、`summary.md`、引用的CSS/assets及证据文件路径，按用户格式要求可只交其中一种；在应用里打开阅读版或给可点击文件链接。最终简短说明文字覆盖、视觉抽样和缺口。只有字幕、视频获取失败或宿主无法读图时，仍可完成文章，但明确“仅文字依据/视觉不可用”，不静默冒充图文理解。

**完成标准**：所需成果可打开、无未替换占位符，标题/图文/评论与证据匹配；双格式不互相矛盾，交付包含真实覆盖边界。
