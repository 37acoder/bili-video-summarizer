# 视觉取材：同源、时间、实际观察

仅在图文模式且已有或可取得视频画面时读取。默认用本地视频、FFmpeg抽帧和宿主Agent读图，沿用宿主额度，无需新的视觉API key。连续动作另读局部序列或片段，视觉覆盖按实际观察范围记录。

## 素材与能力

先确认视频与文字同源、同分P和版本，检查实际时长。优先复用本地视频；ASR缓存纯音轨只提供声音，不能抽帧。需要下载时只取选定视频或分P，沿用已有下载授权。此时检查 `yt-dlp --version`、`ffmpeg -version`、`ffprobe -version`，缺工具时说明实际缺项和替代路径，复用本次安装授权。文字分支无需这些视觉依赖。

匿名公开视频下载的低成本起点：

```sh
# 先创建本次独立visual目录；实际扩展名由下载器确定
# 该低清选型用于浏览筛图，涉及小字时提高质量
# B站URL明确包含用户所选?p=N，不下载整个列表
yt-dlp --ignore-config --no-playlist --retries 1 --socket-timeout 20 \
  -f 'worstvideo[height>=480]/worstvideo/worst' \
  -o '/absolute/job/visual/source.%(ext)s' '完整原片URL'
ffprobe -v error -show_entries format=duration,start_time:stream=index,codec_type,width,height,start_time,time_base \
  -of json '/absolute/job/visual/实际媒体文件'
```

鉴权失败或下载不可用时记录实际失败，不用音频/封面假装视频。可复用用户授权的私有Cookie导出文件（`--cookies`）；本技能的B站JSON认证文件不是Netscape Cookie文件，不能直接传给yt-dlp。凭据不放文章/证据/命令输出，临时凭据完成后清理。无法安全导出时沿用可用本地视频，或明确降级；不为图文流程扩大登录/访问权限。

**完成标准**：可用媒体的来源、分P、版本和实际时长已核对；取材失败时记录原因及可用替代素材，再决定是否降级。

## 候选先总览，再定点

将全文分成能容纳的时间段，先以约30秒间隔低分辨率扫描分布，再结合主题、幻灯片切换和操作密度补采样。30分钟视频30–90张候选、每主题观察3–6张是预算起点，未经最优性验证；信息密集内容可调整。入文数量按信息价值决定，重复口播可以无图。

```sh
# 每页覆盖约300秒；长视频继续用后续start制作总览，不能只读第一页
ffmpeg -nostdin -n -ss 0 -i '/absolute/job/visual/实际媒体文件' -t 300 \
  -vf 'fps=1/30,scale=320:-1,tile=5x2' -frames:v 1 \
  '/absolute/job/visual/contact-000.jpg'
# 选中片段后检查相邻时间，showinfo将解码PTS写到本地日志
ffmpeg -nostdin -n -copyts -ss 555 -i '/absolute/job/visual/实际媒体文件' \
  -vf showinfo -frames:v 1 -q:v 2 \
  '/absolute/job/visual/f001.jpg' 2> '/absolute/job/visual/f001.log'
```

命令中的文件名和时间换成当前素材，运行后检查实际输出。`fps`与tile只用于筛选，不能给出每张原帧的精确时刻，也可能遗漏不足一页的片尾。末页不足300秒时，按候选数量缩小tile并补定点帧，检查真实片尾。小字看不清时从较高清源重新取图，放大低清图不会增加细节。

选图集合覆盖主题附近、画面变化和全片时间补采样，包括无字幕区与片尾。编码I帧只是压缩关键帧，场景检测只是变化信号，两者都不等于语义关键画面。过滤黑屏、转场、模糊、重复口播；保留图表/板书/关键入口/前后状态。短操作与静默演示用更密2–4张有序帧或局部片段。

**完成标准**：候选覆盖首/中/尾，关键主题与静默区没有被漏出计划；每张最终图清晰、信息相关，近邻检查足以排除未展开动画或转场。

## 时间对齐与记录

请求秒数与解码帧时间分别记录。程序提取图像对应的showinfo记录（`n:0`的pts_time），输出小摘要给Agent；证据保留requestedSec和实际ptsSec。日志可能含预读帧，最后一条showinfo未必对应最终图像。

- 媒体起点为零且为完整同版视频：timeSec = 实际ptsSec。
- 媒体有非零start_time：先核对媒体与原片时间轴，通常以 `ptsSec - mediaStartSec` 求文件播放位置；有编辑/偏移异常时先检查片头/已知标记再确认，不能盲套公式。
- 本地片段来自原视频offset：原片时间 = 已确认的片段内播放位置 + offset。offset未知就标无法全局对齐。
- VFR用解码PTS，不能用帧序号除假定FPS。已有分组字幕仅有start时，附近文字范围是近似，不把下一组start当精确句尾。
- 没有文字时间轴时，画面说明只能独立呈现并写未对齐；需对齐则取得带时间转录，不能把全文句子随意塞到截图旁。

证据包含媒体/帧hash、来源与分P、实际时间、选图原因、附近字幕item IDs与对齐精度；局部裁剪保留原帧ID。原帧进文章assets，日志/媒体/候选可留任务缓存，不强制交付完整视频。

**完成标准**：每张选中帧都有来源与实际解码时间，对齐方式和偏移已记录；无法全局对齐的帧明确标注未对齐。

## 用画面解释，不以图片数量验收

每次观察一个有边界的主题：有序原帧、实际时间、局部字幕与待解释问题。记录可见事实、字幕事实、融合推断、未知及冲突；图表的轴、单位、时间范围或数字不清时不写精确结论。没有读图能力就声明不可进行视觉理解，不在文字模型上假装调用视觉。

已验证的单样例经验：425秒曾落在人物镜头，525秒机制图尚未完整展开，545秒绘画流程还只有起始照片；近邻检查后采用完整机制图并用545/555秒序列。可复用经验是“检查附近帧和实际读图”，不是这些固定时间，也不证明自动语义选图已实现。

阶段分别保存下载元数据、帧索引、观察和文章笔记；恢复时核对媒体/字幕hash、分P和抽帧参数再复用。只有有效结果落盘才标完成。失败写实际缺口，不整片重复下载，也不默默换付费API。

**完成标准**：每个视觉断言可回到已观察原帧/片段；动态断言有顺序证据，视觉覆盖标为实际抽样；缺口与文字覆盖分别报告。
